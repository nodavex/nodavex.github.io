Connections

Sample documentation — these pages preview the wiki structure.

nodavex supports two connection approaches, depending on how many servers you want to oversee.

nodavex agent

A direct agent connection gives you a focused view of an individual server from your device.

nodavex fleet

Fleet provides a central connection for monitoring multiple servers together. Each server has its own resource metrics and unread notification count.
