Notifications

Sample documentation — these pages preview the wiki structure.

The Notifications view lists server events with a description, timestamp and severity level.

Severity levels

Events range from informational updates to low, medium, high and critical issues. Use the severity alongside the event description to decide which events need attention.

Example events

  • Disk space running low or elevated memory usage.
  • A database that is unavailable.
  • Completed backups or failed backup verification.
  • Expiring certificates and available updates.
  • Servers reconnecting or services restarting.

Organise your view

Grouping and sorting controls help organise the notification list. The dashboard also shows unread notification counts for each server.
