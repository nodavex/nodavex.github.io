nodavex is a fully open-source service for personal and professional server monitoring. From a home server to a fleet of machines, keep track of resource usage, review notifications and manage your infrastructure from one place. Explore the code, adapt it to your needs and contribute to a monitoring platform built for an open community.

nodavex agent

Connect directly to your nodavex server from the nodavex app for macOS, iPadOS, iOS or the web app. The agent provides a connection to an individual server, giving you a focused view of the machine you want to monitor and control.

Check disk space, CPU and memory usage, and upload and download traffic from the Home dashboard. Review server notifications to identify resource pressure and events that need attention, with access to Actions and Settings from the same app.

nodavex fleet

Connect to nodavex fleet for a central view of multiple servers at the same time. Fleet brings server monitoring and control together, so you can oversee your infrastructure through one connection from your device.

Compare disk usage, CPU and memory consumption, network traffic and unread notification counts across your servers. The expanded dashboard keeps each server’s metrics together, helping you spot differences in resource usage and decide where to focus your attention.

Use the notifications view to review server events with descriptions, timestamps and severity levels. Group and sort updates to make routine activity and urgent issues easier to navigate as your fleet grows.
